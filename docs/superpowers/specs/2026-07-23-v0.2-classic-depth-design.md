# fluo v0.2: Classic Depth Restyle — Design

**Date:** 2026-07-23
**Status:** Approved design, pre-implementation
**One-liner:** Replace the flat Fluent look with an authentic Windows 2000-era chiseled 3D style — four-tone bevels, gradient title bars, square corners — delivered through fully dev-themeable tokens, shipping complete Light and Dark reference themes.

## Goal & Motivation

The library works but reads flat. v0.2 brings back visual depth and "life" in the Windows 2000 idiom: raised buttons, sunken input wells, grooved separators, gradient caption bars, navy selection. This is a wholesale visual-language replacement, not an optional theme — the flat Fluent look is removed.

## Locked Decisions

1. **Full classic Win2000** aesthetic (not modern-depth, not hybrid).
2. **Replace** the flat Fluent look entirely — single render path per control, no style branching, all goldens regenerated. One-way (revert via git if needed).
3. **Authentic 2px four-tone bevels** (raised/sunken), using real system 3D tones.
4. **Gradient title bars** — requires one new renderer primitive.
5. **Fully dev-themeable**: controls carry zero literal colors; every color (including bevel tones and the caption gradient) is a `Theme` token. `SetActive(*Theme)` re-skins everything.
6. **Ship two complete reference themes**: `Light()` (authentic Win2000 gray) and `Dark()` (dark beveled variant, same chisel structure, palette-driven). T-toggle cycles them.

## Bevel Model (four-tone, 2px)

Windows `DrawEdge`-style. Given a rect, drawn as thin `FillRect` edges over a flat face fill:

- **Raised** (buttons, tabs, menu popups, panels, scrollbar buttons, slider thumb):
  - Outermost top edge + left edge = **ButtonHighlight** (white)
  - Inner top + left = **ButtonLight**
  - Inner bottom + right = **ButtonShadow**
  - Outermost bottom + right = **ButtonDarkShadow**
  - Interior filled **ButtonFace**.
- **Sunken** (text wells, list/tree/grid wells, pressed buttons, slider track, progress track, checkbox box):
  - Inverted: outer T/L = ButtonShadow, inner T/L = ButtonDarkShadow; inner B/R = ButtonLight, outer B/R = ButtonHighlight.
  - Interior filled WindowWell (white wells) or ButtonFace (pressed button).
- **Groove** (separators): 1px ButtonShadow then 1px ButtonHighlight (2px etched line).
- **Pressed button** = swap Raised→Sunken and offset the label +1,+1 (classic press nudge).
- **Focus** = the classic 1px dotted/xor focus rectangle inset inside the face. v0 approximation: a 1px `Highlight`-colored inset rectangle (dotted deferred; note it). Applied via the existing focus-ring hook, redrawn classic.

Corners are **square** everywhere (all radius tokens = 0).

## Architecture

### Renderer (one addition)
`render.Renderer` gains:
```go
// DrawGradientRect fills r with a linear gradient from `from` to `to`,
// horizontal when horizontal is true, else vertical.
DrawGradientRect(r render.Rect, from, to render.Color, horizontal bool)
```
The gl impl emits one quad (6 verts) with per-vertex colors — the existing uber-shader already interpolates the per-vertex `aColor` attribute, so **no shader change**: top/left verts = `from`, bottom/right verts = `to`. Used by the title bar (horizontal) and optionally the progress fill. `var _ render.Renderer` assertion stays green; single impl.

Everything else composes from existing `FillRect` (bevels are thin rects). `DrawShadow`/`DrawBackdropBlur` remain in the interface (unused by classic controls; `AcrylicSurface` stays a control but the gallery drops it).

### Bevel helpers (new `controls/bevel.go`)
Palette-driven, read tokens (no literals):
```go
func drawRaised(r render.Renderer, rect render.Rect, face render.Color, c theme.ColorTokens)
func drawSunken(r render.Renderer, rect render.Rect, fill render.Color, c theme.ColorTokens)
func drawGroove(r render.Renderer, rect render.Rect, horizontal bool, c theme.ColorTokens)
func drawFocusRect(r render.Renderer, rect render.Rect, c theme.ColorTokens) // classic inset focus
```
Every control's `Render` is rewritten to call these + a flat face fill, replacing `FillRoundedRect`/`StrokeRoundedRect`. `drawFocusRing` (the shared focus helper) is replaced by `drawFocusRect` (inset, classic).

### Theme
- Rework `ColorTokens` to the classic set above (keep field names controls already use where sensible; add the bevel/caption fields; remove Fluent-only fields like AcrylicTint if unused — or keep harmlessly).
- Metrics: all corner radii = 0; add `BevelWidth = 2`; keep padding scale (maybe tighten by eye).
- Replace `FluentLight()/FluentDark()` with `Light()/Dark()`. `Active()/SetActive()/default` unchanged (default = `Light()`). Update `bind`/examples/gallery references.

## Component Restyle (the sweep)

Each control's `Render` → classic:
- **Button/ToggleButton**: raised face; pressed/checked = sunken + label nudge. Default button = extra 1px DarkShadow outer ring.
- **CheckBox**: sunken white box + black check (existing check glyph/fallback); RadioButton: sunken circle approximated as a small sunken square well (square era) OR keep round with bevel — **round sunken** via existing rounded draw at radius (exception to square: radios stay round). ToggleSwitch: not a Win2000 native — render as a small raised knob in a sunken track (documented as a fluo extension).
- **TextBox**: sunken white well, black text, classic caret.
- **Slider**: sunken track groove + raised rectangular thumb (classic trackbar thumb).
- **ProgressBar**: sunken well + segmented Highlight blocks (classic chunked progress) OR solid Highlight fill (simpler; pick chunked for authenticity).
- **ComboBox**: raised field + a raised drop button with a sunken-on-press; popup = raised list well.
- **ListView/TreeView/DataGrid**: sunken white well; navy `Highlight` selection + white text; grid header = raised cells.
- **TabControl**: raised tabs; selected tab merges into the raised body panel (classic tab notch).
- **Menu/MenuBar**: raised popup panel; item hover = navy Highlight bar; separators = groove.
- **Dialog**: raised gray panel (scrim stays); title via classic caption.
- **ScrollViewer/virtualizer thumb**: raised thumb + sunken track; classic scrollbar buttons deferred (thumb-only stays, restyled raised).
- **TitleBar**: gradient caption (`CaptionFrom→CaptionTo` horizontal) + white caption text left; caption buttons = raised bevel squares with classic min/max/close glyphs; close is NOT red in classic (all gray) — drop the CloseButtonHover red, use raised/pressed.
- **AcrylicSurface**: unchanged as a control; gallery replaces it with a plain raised/gray panel.

## Testing

- Every existing golden regenerated to classic (buttons, toggles, textbox, slider_progress, combo_open, listview, tree_expander, tabs, menu_open, dialog, datagrid, titlebar, fluent_button→classic_button, layout, text stays). Each human-inspected.
- Headless behavior tests (layout, selection, input, binding) are style-agnostic and must keep passing unchanged — bevels are pure Render, no layout/geometry change beyond square corners (radius 0 doesn't move bounds).
- New: `DrawGradientRect` golden; bevel-helper unit reasoning via a golden showing raised/sunken/groove side by side.

## Non-Goals / Deferred (v0.2)

- Dotted XOR focus rectangle (use solid inset line; note).
- Full classic scrollbar with arrow buttons (thumb-only, restyled).
- Period font (keep goregular + SDF; classic look via chrome, not bitmap font).
- Menu keyboard nav, animation (already deferred), IME/a11y.

## Migration Notes

- Public API change: `theme.FluentLight/FluentDark` → `theme.Light/Dark`. `render.Renderer` gains `DrawGradientRect` (breaking for any external Renderer impl — none exist). README/CHANGELOG updated (v0.2 entry: classic restyle).
- Dev-themeability is the headline: document that every color is a token and how to build a custom theme (extend the theme doc + an example).
