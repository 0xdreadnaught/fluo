> **For agentic workers:** Implement per the spec `docs/superpowers/specs/2026-07-23-hd-text-design.md` — it holds the full design and exact behavior; this plan is the ordered task list. Steps use checkbox syntax.

**Goal:** Replace SDF-scaled UI text with crisp direct grayscale-AA glyphs rasterized at device-pixel size and pixel-snapped; keep the SDF path for future scaled/animated text.

**Architecture:** Renderer gains `Scale()` + `DrawGlyphs()` (coverage mode 7). `text` gains a coverage atlas keyed by (glyph, px); `Face.Draw` rasterizes at `round(SizePx×scale)`, sizes quads `rasterPx/scale` (GPU `uScale` maps 1:1), snaps baseline + per-glyph origin. Layout/Measure unchanged.

**Tech Stack:** Go 1.23, go-gl. Build/test via WSL only.
