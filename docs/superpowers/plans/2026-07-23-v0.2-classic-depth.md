# fluo v0.2 Classic Depth Restyle Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Replace fluo's flat Fluent look with an authentic Windows 2000 chiseled 3D style — four-tone bevels, gradient title bars, square corners — via fully token-driven Light and Dark reference themes.

**Architecture:** Add one renderer primitive (`DrawGradientRect`, per-vertex-color quad, no shader change). Add palette-driven bevel helpers (`controls/bevel.go`: raised/sunken/groove/focus) composed from `FillRect`. Rework the theme to two classic token sets (`Light`/`Dark`) with new bevel tones + caption gradient and all corner radii = 0. Rewrite every control's `Render` to call the bevel helpers instead of `FillRoundedRect`/`StrokeRoundedRect`. Regenerate all goldens.

**Tech Stack:** Go 1.23, existing go-gl renderer, no new deps.

## Global Constraints

- Module `github.com/0xdreadnaught/fluo`; go.mod PINNED; WSL-only Go (`wsl -e bash -lc 'cd /mnt/c/Users/dread/source/fluo && <cmd>'`, GOTOOLCHAIN=local); keyed literals; `go vet` + gofmt gates (`/usr/local/go/bin/gofmt`); doc comments on exported identifiers; per-task commit + trailer `Co-Authored-By: Claude Fable 5 <noreply@anthropic.com>`.
- **Controls carry ZERO literal colors** — every color reads a `theme.ColorTokens` field. Bevel tones are tokens. `grep -rn "RGB(\|RGBA(" controls/*.go | grep -v _test` must stay empty after each task.
- **Corners square everywhere**: all radius tokens = 0; `drawRaised`/`drawSunken` draw square rects. (Exception: RadioButton stays round.)
- **Golden discipline**: each task that changes token values OR a control's `Render` regenerates the goldens it affects with `-update` in that same task, so the full suite stays green per task. Human-inspect every regenerated golden. Never `-update` a golden whose inputs you did not change.
- **Behavior tests are style-agnostic**: layout/selection/input/binding tests must keep passing UNCHANGED (bevels are pure `Render`; radius 0 does not move bounds). If a behavior test breaks, the change is wrong — do not edit the test to pass.

**Files:** Modify `render/renderer.go`, `render/gl/batch.go` (or `renderer.go`), `render/gl/renderer_test.go` (+ golden `gradient.png`)

**Interfaces:**
- Produces: `render.Renderer` method

- [ ] **Step 2: gl impl** — in `render/gl` add `DrawGradientRect`. Emit one quad (2 triangles, 6 verts) via the existing `quad`/`vert` batch path BUT with per-vertex colors instead of a single color. The uber-shader already interpolates the per-vertex `aColor` attribute (mode 0, whiteTex), so no shader change. Vertical: top-left/top-right verts = `from`, bottom-left/bottom-right = `to`. Add a small helper `gradQuad(dst render.Rect, cTL, cTR, cBL, cBR render.Color)` emitting 6 verts (TL,BL,BR + TL,BR,TR) each with its corner color, `mode 0`, `whiteTex`. `DrawGradientRect` computes the 4 corner colors from `from`/`to`/`horizontal` and calls it.

### Task 3: bevel helpers

**Files:** Create `controls/bevel.go`, `controls/bevel_test.go`; golden `bevel.png` in `render/gl/renderer_test.go`

**Interfaces:**
- Produces (package `controls`, unexported — used by every control):
```go
// drawRaised paints a 2px four-tone RAISED bevel with a flat `face` interior:
// outer top+left = ButtonHighlight, inner top+left = ButtonLight,
// inner bottom+right = ButtonShadow, outer bottom+right = ButtonDarkShadow.
func drawRaised(r render.Renderer, rect render.Rect, face render.Color, c theme.ColorTokens)
// drawSunken paints the inverted 2px bevel (outer T/L = ButtonShadow, inner T/L
// = ButtonDarkShadow, inner B/R = ButtonLight, outer B/R = ButtonHighlight),
// interior filled `fill`.
func drawSunken(r render.Renderer, rect render.Rect, fill render.Color, c theme.ColorTokens)
// drawGroove paints a 2px etched separator line (ButtonShadow then ButtonHighlight)
// along the center of rect; horizontal true = a horizontal rule.
func drawGroove(r render.Renderer, rect render.Rect, horizontal bool, c theme.ColorTokens)
// drawFocusRect paints the classic 1px inset focus rectangle (Highlight color)
// one px inside rect (solid line; dotted XOR deferred).
func drawFocusRect(r render.Renderer, rect render.Rect, c theme.ColorTokens)
```
Implementation: each edge is a `FillRect`. `drawRaised` fills `face` first, then draws the 4 outer-edge 1px rects (highlight top+left, darkshadow bottom+right), then the 4 inner-edge 1px rects inset by 1 (light top+left, shadow bottom+right). Corners: top/left own the corner pixel (draw left/top full height/width, bottom/right inset by 1 to avoid overdraw — match classic where highlight wins the top-left corner and darkshadow the bottom-right).
